● Done. Here's how variables work:

  Variables section (Functions tab, between function list and view range)
  - Define any number of name = expr pairs, e.g. a = 2, k = pi / 4
  - Names can be any identifier except reserved ones (x, pi, e, i, etc.)
  - Values are full mathjs expressions — sqrt(2), pi / 3, anything works
  - Later variables can reference earlier ones: b = a + 1 resolves correctly
  - Each row shows the resolved value (e.g. ≈0.7854) as feedback
  - Red border if the name is reserved/invalid or the value can't be evaluated

  In functions, use them freely: a * sin(k * x), x^n + c, etc. The scope is
  rebuilt via useMemo whenever variables change and passed straight to evaluate.
