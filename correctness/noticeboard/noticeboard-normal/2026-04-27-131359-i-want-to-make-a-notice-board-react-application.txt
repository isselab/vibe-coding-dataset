  Multiple boards — the home screen shows all your boards as a grid. Click to
  enter, use the back button to return. Admin can create, rename, and delete
  boards. URL hash tracks which board you're on (#<boardId>), so you can share a
   direct link to a board.

  Themes — set when creating or editing a board (pencil icon on the tile). Six
  distinct looks:
  - Cork Board — original warm cork texture
  - Chalkboard — dark green with faint grid lines, grey pins
  - Ocean — deep navy with wave SVG pattern, orange pins
  - Linen — cream crosshatch weave, brown pins
  - Forest — dark green with gold pins
  - Sunset — warm red-orange gradient, gold pins

  Each theme applies via a data-theme attribute and CSS custom properties
  (--pin-head, --toolbar-bg, --card-shadow), so adding more themes later is just
   adding a CSS block.
