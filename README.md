# DATASET

## user-study

Contains two starter projects used for the user study:

- `kanban/` — Kanban board application
- `recipe/` — Recipe application

## correctness

Contains projects and feature models used for the correctness evaluation:

- `FEATURE-MODELS/` — Feature models for each project, organized by project name, with manual, tool, and extracted variants per phase
- `battleship/`, `budget/`, `graphing/`, `noticeboard/`, `timer/`, `workout/` — The evaluated projects, each containing a normal and tool-assisted version alongside their conversation log

These projects have git-histories with commits for each step in development. For nested repository reasons they are saved as git bundles: https://git-scm.com/docs/git-bundle.
